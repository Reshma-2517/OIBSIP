## Objective

To develop a **Python program** that generates a **random password** based on user input.  
The password includes a mix of **special characters, alphabets, and numbers** according to the specified lengths.

---

## Steps Performed / Methodology

1. Imported necessary Python modules: `random` and `string`.  
2. Defined lists for **letters, numbers, and special characters**.  
3. Created a function `random_password()` to:
   - Randomly select the specified number of special characters, numbers, and alphabets.  
   - Combine them into a single list and **shuffle** to ensure randomness.  
   - Convert the list into a string to generate the final password.  
4. Took user input for the number of special characters, alphabets, and numbers.  
5. Validated input:
   - Ensured total length is at least 6 characters.  
   - Handled invalid (non-numerical) inputs using exception handling.  
6. Displayed the **generated random password**.
