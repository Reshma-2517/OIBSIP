## Objective

To develop a **Graphical User Interface (GUI) application** in Python using Tkinter that calculates **Body Mass Index (BMI)**.  
The application allows users to input their weight and height, calculates BMI, and displays the BMI category with color-coded results.

---

## Steps Performed / Methodology

1. Set up a Tkinter window with a fixed size and background color.  
2. Created input fields for weight (kg) and height (cm).  
3. Added a title and labels for clear instructions.  
4. Implemented the **BMI calculation function**:
   - Converts height to meters.
   - Calculates BMI using the formula: `BMI = weight / (height)^2`.
   - Determines the BMI category (Underweight, Normal, Overweight, Obese, Severely Obese).
   - Displays results with **color-coded background** for each category.  
5. Added a **Calculate button** linked to the BMI calculation function.  
6. Handled invalid inputs using exception handling.  
7. Ran and tested the application for different input scenarios.

---

## Tools & Technologies Used

- **Programming Language:** Python 3.x  
- **GUI Library:** Tkinter  
- **IDE / Editor:** vscode  

---

## Outcome / Results

- A fully functional BMI Calculator with:
  - User-friendly interface
  - Color-coded BMI results
  - Error handling for invalid input
- Provides immediate visual feedback based on BMI category:

| BMI Range       | Category         | Color  |
|-----------------|----------------|--------|
| ≤ 18.4          | Underweight     | Blue   |
| 18.5 – 24.9     | Normal          | Green  |
| 25 – 29.9       | Overweight      | Yellow |
| 30 – 39.9       | Obese           | Orange |
| ≥ 40            | Severely Obese  | Red    |
